# GroupGlance

GroupGlance replaces the Looking For Group window in World of Warcraft: Forever (1.60.1) with a compact list. Every group takes one row, so you can see who is in it, what they run and what they still need at a glance.

## Features

- **One row per group or single player**: leader in class colors, level, activity, zone, playstyle and listing age
- **See the group at a glance**: class icons with role badges for every member, plus empty slots
- **Sort** by clicking any column header
- **Filters**: activities, groups or singles, a needed role, playstyle, and a search box for names, dungeons and zones
- **My roles button**: one click shows only groups that need one of your roles
- **Whisper with one click**: on Forever you join a group by whispering its leader. Singles get an Invite button.
- **Whisper marker**: a chat bubble shows which leaders you have already whispered. It turns green when they reply.
- **New listings are highlighted** in gold
- **Refreshes automatically** every 30 seconds while the window is open
- **Hide players** you don't want to see (right-click a row). Undo it from the settings menu.
- **My Listing**: list yourself or your group (activities, playstyle, new player friendly, roles, comment) without leaving GroupGlance
- **Native look**: built from Blizzard's own window, dropdown, button and scroll templates
- **Movable and resizable** window
- **Minimap button**: left-click opens the window, right-click opens the settings

Blizzard's own window can still be opened from the settings menu.

## Installation

1. Download the latest file.
2. Extract the ZIP into `World of Warcraft/_forever_/Interface/AddOns`.
3. Make sure the `GroupGlance` folder is directly inside `Interface/AddOns`.
4. Enable the addon on the character selection screen.

## Commands

| Command | What it does |
| --- | --- |
| `/gg` | Shows or hides the window |
| `/gg blizzard` | Opens Blizzard's own Looking For Group window |
| `/gg reset` | Resets window position and size |
